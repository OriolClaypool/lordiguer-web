El que importa

Una web ha de fer dues coses: explicar bé qui ets i facilitar el pas següent, sigui una reserva, una compra o una trucada. Aquesta mateixa web és un exemple de com treballem.

Què inclou

Una web que treballa

Una bona web es nota en quatre coses que el visitant veu en pocs segons, i que Google també llegeix.

Preguntes freqüents

La web sortirà a Google?
La preparem perquè Google l’entengui bé: textos pensats per a les cerques, velocitat, versió mòbil i dades estructurades. El posicionament també depèn del temps i del contingut que hi vagis afegint.
Podré fer canvis jo mateix?
Si ho necessites, ho tenim en compte des del principi. Si prefereixes no preocupar-te’n, te’ls fem nosaltres amb el manteniment.
Es pot connectar amb el meu sistema de reserves?
Sí. Integrem el motor de reserves o la botiga en línia que ja facis servir.
Quant costa?
Depèn de les pàgines i de les funcions que necessitis. Fem un pressupost tancat després de parlar-ne.
